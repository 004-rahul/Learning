# Start here

This folder is your whole preparation: **one plan, one tracker, one set of notes.** It replaces the old `FAANG-Master-Plan`, `FINAL-PLAN`, `Q-and-A` and `Study-Plan` folders. Every question, answer, problem, design and rule from those folders is kept, either in the notes or word for word in the archive. Known mistakes in the old material are corrected where they appear.

## What to open every day

1. **[TRACKER.xlsx](TRACKER.xlsx)** → sheet **DAILY** → find today → click its week file. (Change the start date on the START sheet once; every date follows.)
2. The **week file** (e.g. [WEEKS/WEEK_01.md](WEEKS/WEEK_01.md)) → jump to **Day N**. It tells you exactly:
   - what to recall first (10 minutes, notes closed),
   - what to learn and which problems to solve (with links),
   - which one or two answers to read (with links into the notes),
   - what to build or try,
   - the question to explain aloud,
   - when the day counts as done.
3. Log in the tracker (5 minutes).

That is all. You do not need to open any other file unless the day links to it.

## Three promises to yourself

- **Do, then read.** Try first; read the answer after.
- **Never invent.** No numbers you did not measure, no stories that did not happen, no features you did not build.
- **Never do zero.** A 30-minute day still counts.
