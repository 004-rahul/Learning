# ⚡ NexusPrep — Local FAANG SDE-2 Command Center

A high-performance, zero-dependency, local web application designed to track and manage your 6–8 month FAANG/MAANG preparation in **under 10 seconds a day**.

---

## 🚀 How to Launch the Web App

### Option 1: Double-Click (Easiest on Windows)
Simply double-click:
👉 **[start.bat](file:///d:/RAHUL/Interview/Learning/prep-app/start.bat)**

It will automatically launch the local server and open your browser at **http://localhost:3000**.

### Option 2: Run via Terminal
Open your terminal in this directory and run:
```bash
node server.js
```
Then visit **[http://localhost:3000](http://localhost:3000)** in any browser.

---

## 🌟 What is Built into This App?

1. **🎯 Today's Mission:**
   * Automatically displays your current day's target, pattern, and deliverable.
   * Visual 4-step 120-minute time allocation breakdown.
   * Built-in 4-line micro-note editor that automatically saves to `localStorage`.
   * Real-time spaced repetition alerts showing which topics from 3d, 7d, or 14d ago are due for quick active recall today.
   * 1-Click completion toggle updating your streak and overall completion percentage.

2. **🗺️ Interactive 224-Day Roadmap:**
   * Browse, filter, and search all 224 days by Phase, Track, or keyword.
   * Jump directly to any day with one click.

3. **🧩 DSA Pattern Encyclopedia:**
   * All 14 patterns with expandable mental models, sub-patterns, failure points, and direct LeetCode links.

4. **🏗️ System Design Hub (HLD & LLD):**
   * 8 Anchor High-Level Design systems.
   * 7 Anchor Low-Level Design machine coding systems with C# design patterns.
   * Comprehensive Single Points of Failure (SPOF) resilience checklist.

5. **🛠️ NexusQueue Project Tracker:**
   * Interactive phase-by-phase checklist for your distributed AI task platform.

6. **🎭 Behavioral STAR Story Bank:**
   * 6 core interview stories mapped to your real production achievements at Casepoint and Vision Infotech.

7. **⚠️ Mistake Register:**
   * Quick form to record and review your friction points.

8. **💾 Backup & Portability:**
   * **Backup Data:** Export your entire state (progress, notes, checklist) as a single JSON file.
   * **Import Backup:** Restore your progress on any browser or machine with one click.
